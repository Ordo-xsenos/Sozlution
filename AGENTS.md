# Руководство AI-агента Sozlution

## Обзор архитектуры
- **Frontend**: Next.js 16.2.0 (React 19) приложение со статическим экспортом, развернутое на Vercel
- **UI фреймворк**: Компоненты shadcn/ui с примитивами Radix UI, Tailwind CSS, поддержка темной темы
- **AI интеграция**: Компонент чат-бота (`components/ai-chatbot.tsx`) вызывает маршрут `/api/chat`, который проксирует запросы к внешнему AI API (OpenAI/Gemini)
- **Backend**: Python/Django (определено в `../sozlution-backend/openapi.yml`), но frontend является автономным Next.js
- **Мультиязычность**: Поддержка английского, узбекского и русского языков через объекты переводов в компонентах
- **API типы**: Генерируются из `../sozlution-backend/openapi.yml` с помощью `pnpm gen:api-types` → `lib/api-types.ts`
- **Глобальное состояние**: Контекст приложения (`context/app-context.tsx`) для управления пользовательскими данными, статистикой и планом обучения

## Рабочий процесс разработки
- **Менеджер пакетов**: pnpm (используйте `pnpm install`, `pnpm dev`, `pnpm build`)
- **Локальная разработка**: `pnpm dev` запускает сервер разработки на localhost:3000
- **Сборка**: `pnpm build` создает статический экспорт в `.next/`
- **Линтинг**: `pnpm lint` запускает ESLint
- **Генерация типов**: Запускайте `pnpm gen:api-types` после изменения `../sozlution-backend/openapi.yml`

## Паттерны кода
- **Псевдонимы путей**: Используйте `@/*` для импортов из корня проекта (настроено в `tsconfig.json`)
- **Структура компонентов**: UI компоненты в `components/ui/`, эффекты в `components/effects/`
- **Стилизация**: CSS переменные для темизации, классы Tailwind, `globals.css` для базовых стилей
- **AI чат**: Ответы с фильтрацией по темам (только темы Sozlution/изучения английского), резервные варианты с захардкоженными ответами
- **Интернационализация**: Объекты перевода с ключами `en`/`uz`/`ru`, проп языка передается в компоненты
- **Формы**: React Hook Form с валидацией Zod (например, в `components/ui/form.tsx`)
- **Анимации**: Библиотека `tw-animate-css` для ключевых кадров, эффекты типа `click-spark.tsx`
- **Глобальное состояние**: Используйте `AppProvider` и `useApp` хук для доступа к пользовательским данным, статистике и API запросам
- **3D эффекты**: Компоненты с `@react-three/fiber` для интерактивных анимаций

## Ключевые файлы
- `app/page.tsx`: Главная целевая страница с переводами, разделами функций и тарифов
- `components/ai-chatbot.tsx`: Плавающий чат-бот с быстрыми вопросами, интеграцией с API
- `app/api/chat/route.ts`: Маршрут AI прокси с фильтрацией тем и API вызовами, совместимыми с OpenAI
- `lib/api-types.ts`: Сгенерированные типы API (регенирировать после изменений `../sozlution-backend/openapi.yml`)
- `tailwind.config.ts`: Цвета темы, анимации, интеграция shadcn/ui
- `next.config.js`: Конфигурация статического экспорта
- `context/app-context.tsx`: Глобальный контекст приложения с данными пользователя, статистикой и API функциями
- `app/mvp/`: Страницы основного приложения (learn, progress, settings и т.д.)

## Переменные окружения
- `AI_API_URL`: URL внешнего AI API (совместим с OpenAI/Gemini)
- `AI_API_KEY`: API ключ для внешнего AI сервиса
- `AI_MODEL`: Название модели (по умолчанию gpt-3.5-turbo)

## Деплой
- Статический экспорт на Vercel (настроено в `vercel.json`)
- Без серверного рендеринга; все страницы являются статическими HTML/JS
